# **App Name**: CEP Reverso

## Core Features:

- Entrada de Endereço: Campos de entrada para nome da rua, bairro e cidade.
- Pesquisa de CEP Reverso: Use uma ferramenta LLM para encontrar uma lista de CEPs e nomes de ruas correspondentes, dado o endereço de entrada.
- Exibição de Resultados: Exibir a lista de CEPs e nomes de ruas em formato de tabela.
- Copiar CEP: Capacidade de copiar o CEP selecionado para a área de transferência.

## Style Guidelines:

- Cor primária: Azul profundo (#3F51B5) para transmitir confiança e confiabilidade.
- Cor de fundo: Cinza claro (#F0F2F5) para uma aparência limpa e profissional.
- Cor de destaque: Teal (#009688) para destacar elementos interativos.
- Fonte sans-serif limpa e legível para campos de entrada e exibição de resultados.
- Ícones simples e geométricos para ações de cópia e estados de carregamento.
- Layout claro e estruturado para entrada de endereço e resultados de pesquisa.
